# Paradise Nursery

Paradise Nursery is a React and Redux Toolkit shopping cart for an online houseplant shop. Browse 18 plants across three categories, add plants to the cart, and adjust quantities or remove items. Checkout is a demonstration.

## Run locally

1. Run `npm ci` to install dependencies.
2. Run `npm run dev` and open the local URL printed by Vite.
3. Run `npm run build` to create a production build.

Plant images are AI-generated illustrations of the listed varieties.
